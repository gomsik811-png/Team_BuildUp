- 팀 전체 기능: 경기 일정·스코어, 구단별 팬 커뮤니티, 승부예측, AI 축구 도우미

선택한 이미지를 제출 전에 확인하고, 누락된 입력과 일부 첨부 실패를 구분해 안내했습니다.

- 파일명·크기·수정 시각으로 중복 선택을 걸러내고 기존 첨부 목록에 추가했습니다.
- Object URL로 이미지 미리보기를 만들고 정리 시 revokeObjectURL을 호출했습니다.
- 제목·내용별 오류를 표시하고 첫 번째 누락 입력으로 포커스를 이동했습니다.

[관련 코드·PR](https://github.com/PSK6262/Team_BuildUp/commit/12295c8d5803680b9333086ebcf30c3df66965c6)

## 주요 처리 흐름

1. **React 위젯**: 질문을 입력하고 /api/chatbot/ask로 요청합니다.
2. **Spring MVC**: 빈 질문과 길이를 검사하고 공통 응답 형식으로 반환합니다.
3. **DAO · MyBatis**: 최근 경기와 예정 경기 데이터를 조회합니다.

위젯 위치는 localStorage에 저장하고 화면 밖으로 벗어나지 않도록 제한했습니다.

## 문제 해결 기록

### 챗봇 질문을 서버에서도 검증

**문제·상황:** 챗봇 질문 API에서는 화면에서 전달된 질문이 비어 있거나 허용 길이를 넘는 경우를 처리해야 했습니다.

**처리:**

- /api/chatbot/ask에서 질문을 받아 빈 값과 공백을 확인했습니다.
- 질문 길이를 최대 1,000자로 제한했습니다.
- 검증 결과와 처리 응답을 공통 응답 형식으로 반환했습니다.

**변경 결과:** 질문 API에 빈 값·길이 검증을 추가하고 응답 형식을 정리했습니다.

**고려 사항:** 입력 화면의 검사와 별개로 서버에서도 요청값을 검증하도록 처리했습니다.

[근거](https://github.com/PSK6262/Team_BuildUp/commit/57804c3f64a219e33f941df11a6fb6a18ab7a668)

### 이미지 재선택 시 기존 첨부 유지

**문제·상황:** 게시글 작성 시 여러 번 파일을 선택할 수 있지만, 기존 방식은 선택 파일을 이름 목록으로 보여주고 새 선택으로 목록을 대체했습니다.

**처리:**

- 기존 목록을 유지한 채 새 파일을 합치고 파일명·크기·수정 시각이 같은 파일은 중복으로 추가하지 않았습니다.
- 선택한 파일마다 Object URL을 생성해 미리보기와 개별 제거 버튼을 제공했습니다.
- 파일이 바뀌거나 컴포넌트가 정리될 때 Object URL을 해제하고, 미리보기 실패 시 파일명을 보여주었습니다.

**변경 결과:** 작성 화면에서 선택한 이미지를 확인·추가·제거할 수 있게 변경했습니다.

**고려 사항:** 미리보기는 파일 선택 상태를 보여주는 기능이므로, 실제 업로드 성공 여부와 별도로 안내해야 했습니다.

[근거](https://github.com/PSK6262/Team_BuildUp/commit/12295c8d5803680b9333086ebcf30c3df66965c6)

### 글 저장 성공과 첨부 실패를 따로 안내

**문제·상황:** 게시글 등록 후 첨부파일 업로드가 일부 실패하면, 사용자가 글까지 저장되지 않았다고 오해할 수 있습니다.

**처리:**

- 게시글 생성 뒤 첨부 업로드 결과를 따로 확인했습니다.
- 일부 첨부 실패 시 상세 페이지 이동 주소에 attachmentError를 전달했습니다.
- 공통 토스트에서 정상 등록과 일부 첨부 실패를 다른 메시지로 안내했습니다.

**변경 결과:** 게시글이 등록되었다는 사실과 일부 파일이 업로드되지 않았다는 상태를 함께 전달하도록 수정했습니다.

**고려 사항:** 여러 요청으로 나뉜 작업에서는 전체 성공·실패뿐 아니라 부분 성공 상태도 사용자에게 전달해야 했습니다.

[근거](https://github.com/PSK6262/Team_BuildUp/commit/12295c8d5803680b9333086ebcf30c3df66965c6)
